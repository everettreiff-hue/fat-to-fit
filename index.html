Auto-Sync via iOS Shortcut — Hands-Free
Set up once. After each scan, run the Shortcut and your data appears here instantly on all devices.
Waiting for first sync from Shortcut…
One-time setup on your iPhone:
1. Open the Shortcuts app → tap + to create a new Shortcut
2. Add action: Get Samples from Health → Type: Body Mass → Limit: 1, Sort by: most recent
3. Add Get Samples from Health → Type: Body Fat Percentage → Limit: 1
4. Add Get Samples from Health → Type: Lean Body Mass → Limit: 1
5. Add action: Get Current Date
6. Add action: Text → paste this (replace each with the result variables from above):
{"fields":{"date":{"stringValue":"DATE"},"weight":{"doubleValue":WEIGHT},"pbf":{"doubleValue":BODYFAT},"leanBodyMass":{"doubleValue":LEAN},"pendingImport":{"booleanValue":true},"syncedAt":{"stringValue":"DATE"}}} 7. Add action: Get Contents of URL:
  URL: https://firestore.googleapis.com/v1/projects/e-health-tracker/databases/(default)/documents/health/hume_sync?key=AIzaSyCxPlVaKYAHet2PAiz19VqByW8Ws2W5_1Q
  Method: PATCH, Request Body: JSON → the Text from step 6
8. Name it "Log Hume Scan" and add it to your Home Screen

After each Hume scan, tap that icon — your data appears in this app within seconds.

CSV Import

Import from Whoop / Apple Health CSV export. Columns: date, weight, body_fat, visceral_fat, subcutaneous_fat, muscle_mass, workout, recovery, notes.

Downloads this app as a single HTML file with your data baked in. Use this to set up the app on a new computer — open the file and everything is already there.
